# Tovix

Online identity for **Tovix** — a game development studio.

## Website

Lean Next.js studio site:

- **Home** — brand-first hero with the official mark
- **Games** — showcase list
- **About** — studio story
- **Contact** — mailto contact form + socials

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit studio copy and socials in `src/data/studio.ts`.  
Edit game listings in `src/data/games.ts`.

## Brand pack

Offline kit in [`brand/`](./brand/):

- Official logo PNGs + SVG approximations
- Color tokens (`brand/colors/`)
- Studio bios and usage rules (`brand/README.md`)

## Stack

Next.js · TypeScript · Tailwind CSS · Oxanium + Rajdhani
